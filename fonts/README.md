# Schriften

Die Vorlage der Hochschule Harz verwendet **Helvetica Neue**. Die Schriftdateien sind lizenzpflichtig und
deshalb nicht im Ordner enthalten.

Für das Original-Schriftbild die Helvetica-Neue-Dateien (z. B. aus der Vorlage „Webservices Hausarbeit“,
Ordner `fonts/`) hier ablegen:

```
h-folien/fonts/LTe50259.ttf
h-folien/fonts/LTe50261.ttf
h-folien/fonts/LTe50265.ttf
```

Ohne diese Dateien nimmt Typst die erste installierte Ersatzschrift aus `template.typ`:
TeX Gyre Heros (freier Helvetica-Nachbau), dann Liberation Sans, dann Arial. Warnungen
`unknown font family` für fehlende Schriften der Liste sind normal.
